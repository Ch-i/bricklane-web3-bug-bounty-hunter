# NTE-3 | Setting Default Values

_Section severity (from Solodit section header): Low_  
_Audit firm: Guardian Audits_  
_Source report: [2022-05-09-Ethernote.md](https://github.com/solodit/solodit_content/blob/main/reports/Guardian%20Audits/2022-05-09-Ethernote.md)_

---

**Description**

The variables `circulatingNotes` and `fees` are assigned to 0. This is unnecessary because the default value for the `uint256` type is 0.

**Recommendation**

Remove the assignment.

**Resolution**

Ethernote Team:

- Remove the 0 assignment as `uint256` defaults to 0
