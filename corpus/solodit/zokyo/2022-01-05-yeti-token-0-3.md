# Variable ‘TOTAL_SUPPLY’ has no decimals

_Section severity (from Solodit section header): High_  
_Audit firm: Zokyo_  
_Source report: [2022-01-05-Yeti Token.md](https://github.com/solodit/solodit_content/blob/main/reports/Zokyo/2022-01-05-Yeti%20Token.md)_

---

**Description**


Standard ERC20 token has 18 decimals, however decimals of ‘TOTAL_SUPPLY’ are missing.

**Recommendation**:

Add decimals for variable(e.g. TOTAL_SUPPLY = 100000000e18).
