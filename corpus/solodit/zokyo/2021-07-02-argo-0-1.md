# Unsafe calculation

_Section severity (from Solodit section header): Medium_  
_Audit firm: Zokyo_  
_Source report: [2021-07-02-ArGo.md](https://github.com/solodit/solodit_content/blob/main/reports/Zokyo/2021-07-02-ArGo.md)_

---

**Description**

In contract YieldFarm.sol (argo-yieldfarming-staking-master), in function massHarvest there is
a calculation without safe math check:
totalDistributedValue += _harvest(i);

**Recommendation**:

Add safe math:
totalDistributedValue = totalDistributedValue.add(_harvest(i));
