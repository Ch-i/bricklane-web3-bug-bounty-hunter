# Inverse `if-else` statements  that have a negation

_Section severity (from Solodit section header): Informational_  
_Audit firm: Zokyo_  
_Source report: [2023-12-23-Avantis.md](https://github.com/solodit/solodit_content/blob/main/reports/Zokyo/2023-12-23-Avantis.md)_

---

**Severity**: Informational

**Status**: Resolved

**Description**

In contract PairInfo, the method lossProtectionTier(...) has a `if-else` statement 

```solidity
       if (!_trade.buy) {
          action1
       } else {
          action2
       }
```

Can be switched to save gas.
```solidity
 if (_trade.buy) {
          action2
       } else {
          action1
       }
```
