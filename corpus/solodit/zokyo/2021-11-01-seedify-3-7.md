# Unnecessary returning of bool.

_Section severity (from Solodit section header): Informational_  
_Audit firm: Zokyo_  
_Source report: [2021-11-01-Seedify.md](https://github.com/solodit/solodit_content/blob/main/reports/Zokyo/2021-11-01-Seedify.md)_

---

**Description**

Functions _payMe(), _payTo(), _payDirect() don’t need to return bool, since they can only either
return true or revert.

**Recommendation**:

Remove returning of bool.
