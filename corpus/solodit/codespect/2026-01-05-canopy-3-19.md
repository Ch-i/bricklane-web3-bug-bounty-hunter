# [I-20] Redundant code

_Section severity (from Solodit section header): Informational_  
_Audit firm: CODESPECT_  
_Source report: [2026-01-05-Canopy.md](https://github.com/solodit/solodit_content/blob/main/reports/CODESPECT/2026-01-05-Canopy.md)_

---

**Files:** [`validation.rs`](https://github.com/canopyfi/canopy/blob/234cd9ca0ca8348e466548513d72a2aba65e84e4/programs/canopy/src/utils/validation.rs#L5)

**Original severity:** Best Practices

**Description:**

In `validation.rs`, `SafeMath` and its implementation are redundantly defined, as they have already been implemented in `safe_math.rs`.

```rust
pub struct SafeMath;

impl SafeMath {
    //...
}
```

**Impact:** Redundant code increases readability difficulty, enlarges the program size, and raises deployment costs.

**Recommendation:** It is recommended to remove the redundant `SafeMath` definition.

**Status:** Fixed
