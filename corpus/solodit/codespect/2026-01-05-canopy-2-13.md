# [L-14] Improper authorization in the mark_tge_ready(...) instruction

_Section severity (from Solodit section header): Low_  
_Audit firm: CODESPECT_  
_Source report: [2026-01-05-Canopy.md](https://github.com/solodit/solodit_content/blob/main/reports/CODESPECT/2026-01-05-Canopy.md)_

---

**Files:** [`mark_tge_ready`](https://github.com/canopyfi/canopy/blob/a26f759987b60d503781485eb1743b8cd5cc1463/programs/canopy/src/instructions/tge/mark_tge_ready.rs#L108)

**Description:**

The `mark_tge_ready(...)` instruction allows a `grove_admin` to call it.

```rust
let is_platform_admin = AuthUtils::is_platform_admin(admin, &platform_config.key());
let is_grove_admin = admin.targets.contains(&grove.key());
let is_seedling_admin = admin.targets.contains(&seedling.key());

require!(
    is_platform_admin || is_grove_admin || is_seedling_admin,
    ErrorCode::Unauthorized
);
```

However, this instruction sets some parameters such as `token_mint` that are normally set by the `update_tge_distribution(...)` instruction and should only be allowed to be set by the `seedling_admin`.

**Impact:** A `grove_admin` could call the `mark_tge_ready(...)` instruction to start the TGE before the `seedling_admin` calls `update_tge_distribution(...)`, potentially modifying some parameters set by the `seedling_admin`.

**Recommendation:** It is recommended not to allow a `grove_admin` to call `mark_tge_ready(...)`.

**Status:** Fixed

**Client response:** Want grove admins to be able to do this as well. I added check to ensure that TGE is properly configured before `mark_tge_ready()` <https://github.com/canopyfi/canopy/commit/c4b19349aef89c68477324a479cb2ed7474ad1a6>

**CODESPECT fix review:** If that is the case, we suggest removing this instruction’s ability to reconfigure `token_mint` and `total_tokens`. The `escrow_token_account` may not be the expected account (the system does not enforce it to be an ATA), which could result in an incorrect `total_tokens` amount and `token_mint`.

**Client response:** <https://github.com/canopyfi/canopy/commit/f264403f43335205b57cf047870f672266b97954> Simplifies `mark_tge_ready` by removing the ability to change token configuration at activation time - those parameters must now be configured beforehand via `update_tge_distribution`
