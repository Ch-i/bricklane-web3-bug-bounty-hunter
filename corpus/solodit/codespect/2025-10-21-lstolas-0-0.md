# [H-01] The LzOracle contract doesn’t assign any value to the depository address

_Section severity (from Solodit section header): High_  
_Audit firm: CODESPECT_  
_Source report: [2025-10-21-lstOlas.md](https://github.com/solodit/solodit_content/blob/main/reports/CODESPECT/2025-10-21-lstOlas.md)_

---

**Files:** [`LzOracle.sol`](https://github.com/LemonTreeTechnologies/olas-lst/blob/e9d19b7fb08288f829cba8243d91e80ebde745a6/contracts/l1/bridging/LzOracle.sol#L102)

**Description:**

The `depository` variable is declared as:

```solidity
// Depository address
address public immutable depository
```

However, it is never assigned in the constructor (nor at declaration). Since it is not set, any external calls to `IDepository(depository)` would silently target a nonexistent address.

**Impact:** Any calls to the `depository` address will fail.

**Recommendation(s):** Assign a value at constructor or hardcode correct address in the contract.

**Status:** Fixed

**Client response:** PR with fix: [https://github.com/kupermind/olas-lst/pull/42](https://github.com/kupermind/olas-lst/pull/42)
