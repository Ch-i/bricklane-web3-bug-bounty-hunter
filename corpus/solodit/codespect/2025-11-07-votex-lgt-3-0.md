# [I-01] The operator account is not used

_Section severity (from Solodit section header): Informational_  
_Audit firm: CODESPECT_  
_Source report: [2025-11-07-Votex-LGT.md](https://github.com/solodit/solodit_content/blob/main/reports/CODESPECT/2025-11-07-Votex-LGT.md)_

---

**Files:** [`init_alock.rs`](https://github.com/VotaFi/lgt-adrena/blob/3eca6d0d04c5055da163ccfc83413ab8af10aef5/programs/adrena-lock/src/instructions/admin/init_alock.rs#L146)

**Description:**

The `init_alock` instruction populates the `alock.operator` with the provided `initial_operator` account:

```rust
alock.operator = self.initial_operator.key();
```

The protocol provides also the `transfer_operator` and `accept_operator` instructions to handle the operator handover. The `operator` account is however not required for any operation within the protocol hence it is unnecessary.

**Impact:** Unnecessary functionality

**Recommendation:** Remove the `operator` member from `alock`.

**Status:** Fixed
