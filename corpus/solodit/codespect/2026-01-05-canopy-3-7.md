# [I-08] Missing mut constraint on platform_collection

_Section severity (from Solodit section header): Informational_  
_Audit firm: CODESPECT_  
_Source report: [2026-01-05-Canopy.md](https://github.com/solodit/solodit_content/blob/main/reports/CODESPECT/2026-01-05-Canopy.md)_

---

**Files:** [`deposit.rs`](https://github.com/canopyfi/canopy/blob/1b3b043dc962bbab89ffbcb1052650f4eea58dbc/programs/canopy/src/instructions/watering/deposit.rs#L65C9-L65C28)

**Description:**

In the `deposit(...)` instruction, the `platform_collection` account is passed in. This account is expected to be modified in the instruction, specifically the `total_minted` and `updated_at` fields.

```rust
{
    let platform_collection = &mut ctx.accounts.platform_collection;
    platform_collection.total_minted += 1;
    platform_collection.updated_at = current_time;
}
```

However, in ctx, this account is not marked as `mut`.

**Impact:** Not marking the account as `mut` but modifying its data will cause the changes not to be persisted on-chain. The instruction will execute successfully, but the `total_minted` and `updated_at` fields will not be updated.

**Recommendation:** Mark `platform_collection` as `mut`.
