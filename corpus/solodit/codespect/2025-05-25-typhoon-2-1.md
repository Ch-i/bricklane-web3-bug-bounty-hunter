# [M-02] Updating the current_day always adds an additional day

_Section severity (from Solodit section header): Medium_  
_Audit firm: CODESPECT_  
_Source report: [2025-05-25-Typhoon.md](https://github.com/solodit/solodit_content/blob/main/reports/CODESPECT/2025-05-25-Typhoon.md)_

---

**Files:** [`Pool.cairo`](https://github.com/typhoonmixer/typhoon-contracts/blob/a148cf0c83d28e98b1bd21af301bfd55f9a9c3f7/src/Pool.cairo#L245)

**Description:**

Deposits and withdrawals always call the `updateDay(...)` function to check if a day has passed since the storage variable `current_day`. However, if at least a day has passed and `current_day` needs to be updated, an additional day is always added:

```cairo
fn updateDay(ref self: ContractState) {
    let mut cur_day = self.current_day.read();
    let mut dif: u256 = 0;
    if cur_day < get_block_timestamp().into() {
        dif = get_block_timestamp().into() - cur_day;
        if dif > day.into() {
            let days = getDaysPassed(@cur_day);
            self.current_day.write(cur_day + (day.into() * days) + day.into()); // @audit-issue an additional day gets added
        }
    }
}
```

**Impact:** Inaccurate tracking of the days, since every time the `current_day` gets updated, an additional day gets added.

**Recommendation:** Remove the `+ day.into()` part of the calculation.

**Status:** Fixed
