# MLIR-MRacle: Memory-Model-Aware Metamorphic Fuzzing of Concurrent MLIR

_arXiv ID: 2611.24804_  
_Authors: Aaron Gabayoyo, Aidan Dakhama, Ajitha Rajan_  
_Published: 2026-11-18_  
_Note: 4 pages, 1 figure_  
_Source: [https://arxiv.org/abs/2611.24804v1](https://arxiv.org/abs/2611.24804v1)_

## Abstract

Multi-level compilers built on MLIR lower concurrent programs through many stages towards targets with potentially drastically different memory models, where an optimisation which appears reasonable, can silently change program behaviour. Testing these lowerings is hard: a concurrent program often has no single expected outcome, and existing MLIR fuzzers often assume determinism. We present MLIR-MRacle, a memory-model-aware metamorphic fuzzer for concurrent MLIR programs. MLIR-MRacle applies metamorphic relations gated by the target memory model, so that both the original and transformed programs remain well defined - executing both repeatedly, and comparing their outcome sets or distributions withone of two statistical oracles. A coverage guided campaign driver built on libafl is used to perform continuous fuzzing. MRs, memory models, oracles, and execution backends all provide extension points for future researchers and compiler engineers to build off this package. In a case study on Armv8 hardware, MLIR-MRacle ran over 145k trials across four configurations, reaching up to 93.6k compiler coverage edges, and found a bug in the OpenMP dialect verifier that has since been fixed upstream.
